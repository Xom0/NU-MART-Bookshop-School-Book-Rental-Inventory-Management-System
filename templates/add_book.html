Add Textbooks

Create a textbook classification or add more physical copies to an existing textbook.

Back to Inventory

1. New Textbook

Create a new textbook classification and generate its first physical copies.

A unique classification ID and individual Book IDs will be generated automatically. Poor-condition books cannot be rented.

Example generated IDs

Classification: BK-MAT-001

Physical copies: BK-MAT-001-001, BK-MAT-001-002

2. Add Copies

Select a textbook already in the catalogue and add more physical copies without re-entering its details.

Existing physical copies will not be modified. Only new copies will be added.

Example

If BK-MAT-001 already contains an older copy called BK001, a new copy can receive BK-MAT-001-001.

Both physical copies will belong to the same classification.
